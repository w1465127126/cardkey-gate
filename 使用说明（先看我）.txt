========================================
  卡密系统 · 使用说明
========================================

【文件夹里有什么】

  ① 卡密管理端.exe        ← 你用的。生成卡密、推送到 GitHub
  ② 卡密校验器.exe        ← 非 Python 程序用这个卡一道
  ③ 示例受保护程序.exe    ← 演示"点开就要卡密"的效果
  keys.json               ← 卡密库模板，传到 GitHub 仓库
  README.md               ← 完整文档（字段表、错误码、打包命令）
  源码\                   ← 全部 Python 源码 + 打包脚本
  测试\                   ← 自测脚本，48 项

========================================
【5 分钟跑通】
========================================

第 1 步 · 建 GitHub 仓库
  GitHub 新建仓库（公共的就行），里面新建文件 keys.json，
  内容复制本目录的 keys.json 进去。

  然后拿一个令牌：GitHub → Settings → Developer settings
  → Personal access tokens → Tokens (classic)
  → Generate new token → 勾 repo → 生成，把 token 复制下来

第 2 步 · 打开 ① 卡密管理端.exe
  第一排填：
    仓库 owner/repo  =  你的用户名/仓库名
    文件路径          =  keys.json
    分支              =  main
    PAT Token         =  刚才复制的令牌
  点【测试连接】→ 显示 "✅ 已连接" 就通了

第 3 步 · 生成卡密
  在"② 生成卡密"区：
    APP_ID    =  MY_APP   ← 要和你的程序里写的一致
    有效期(天) =  0        ← 0=永久，30=30天
    次数       =  0        ← 0=不限，1=只能激活一次
    生成数量   =  10
  点【生成卡密】→ 再点【推送仓库】→ 完事

  想发卡就点【复制本次生成的卡密】或【导出 TXT】（存桌面）。
  想作废：列表里选中 →【吊销选中】→【推送仓库】，立即生效。

第 4 步 · 让程序要卡密
  先在 ③ 示例受保护程序.exe 上试：
  用记事本打开 源码\demo_protected_app.py，
  把 REPO 和 RAW_URL 改成你自己的仓库地址，
  然后 源码\build.bat 重新打包，就能看到效果。

  你自己的 Python 程序，加三行：
      import cardkey_sdk
      if not cardkey_sdk.gate(app_id="MY_APP", repo="你的用户名/仓库名",
                              raw_url="https://raw.githubusercontent.com/你的用户名/仓库名/main/keys.json"):
          raise SystemExit

  非 Python 程序（bat / 任意 exe），用 ② 卡密校验器.exe：
      "② 卡密校验器.exe" --check %1
      if errorlevel 1 ( echo 卡密无效 & pause & exit /b 1 )
      start "" "你的程序.exe"
  同目录放 keycheck.json 告诉它去哪查（格式见 README.md）

========================================
【常用功能速查】
========================================

  一卡一机      勾【首次使用自动绑定机器】，谁先用锁谁
  指定机器      点【我的机器码】拿到码，填进【绑定机器码】
  限时卡        有效期填天数；0 = 永久
  一次性卡      次数填 1
  批量发卡      生成数量填 50，然后导出 TXT
  离线也能进    通过一次后 30 天内断网可用
  防手改 JSON   管理端和 SDK 都填同一个 HMAC secret（可选）

========================================
【重要提醒】
========================================

  · 打开 ① 管理端.exe 时，Windows 可能弹"未知发布者"，
    点【更多信息】→【仍要运行】即可（自己打的包没签名，正常）。

  · 如果"测试连接"失败：先确认 token 有没有勾 repo 权限、
    仓库名有没有写错（格式是 用户名/仓库名，不要带 https://）。

  · 卡密库用私有仓库也能用，但客户端要内嵌只读 token。

  详细内容看 README.md
